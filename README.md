# 🎧 Social Media Music Search App

This project is a full-stack music search website that allows users to find and play songs from **SoundCloud**, **YouTube**, and **Spotify** using data from **RapidAPI**.

...

## 📌 Notes

- You must register and subscribe to [RapidAPI](https://rapidapi.com/) to use the APIs.
- YouTube and Spotify may return limited data or previews depending on the API access.
- Host the frontend separately on GitHub Pages and backend on platforms like Railway, Render, or Vercel if deploying online.
